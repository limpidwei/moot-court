### 一、请求权基础检索（按排序逐一检视）

#### 1. 合同请求权（《民法典》合同编）

*   **是否可能适用？** **是。** 本案案由为“借款合同纠纷”，核心法律关系是借款合同。合同请求权是处理此类纠纷最直接、最优先的请求权基础。
*   **积极成立要件（主要规范）：**
    *   **《民法典》第六百七十九条**：自然人之间的借款合同，自贷款人提供借款时成立。
    *   **《民法典》第六百七十五条**：借款人应当按照约定的期限返还借款。对借款期限没有约定或者约定不明确，依据本法第五百一十条的规定仍不能确定的，借款人可以随时返还；贷款人可以催告借款人在合理期限内返还。
    *   **《民法典》第六百七十六条**：借款人未按照约定的期限返还借款的，应当按照约定或者国家有关规定支付逾期利息。
    *   **《民法典》第六百八十条**：禁止高利放贷，借款的利率不得违反国家有关规定。借款合同对支付利息没有约定的，视为没有利息。
*   **要件事实分析（假设场景）：**
    *   **要件1：借款合同成立。** 需要证明原告（出借人）与被告（借款人）之间达成了借款合意（如借条、微信聊天记录等），并且原告实际向被告交付了借款（如银行转账记录、现金收据等）。
    *   **要件2：借款期限届满或经催告。** 假设未约定还款期限，原告需要证明其已向被告发出催告，并给予了合理期限。
    *   **要件3：被告未按期返还借款。** 需要证明被告在约定的还款日或催告的合理期限届满后，仍未履行还款义务。
    *   **要件4：主张利息。** 假设未约定利息，则视为无利息，原告只能主张逾期利息。需要证明被告逾期还款的事实。
*   **防御规范（被告视角）：**
    *   **《民法典》第六百七十九条**：被告可能抗辩原告未实际提供借款，或提供的金额与借条不符（如存在“砍头息”）。
    *   **《民法典》第六百七十五条**：被告可能抗辩原告从未进行催告，或催告后给予的还款期限不合理。
    *   **《民法典》第六百八十条**：被告可能抗辩原告主张的利息或逾期利率超过了法律保护的上限（LPR四倍）。
    *   **《民法典》第一百九十二条**：被告可能提出诉讼时效抗辩。

#### 2. 类似合同请求权（缔约过失、无权代理等）

*   **是否可能适用？** **否。** 本案是典型的合同履行纠纷，双方已成立借款合同关系，不存在合同未成立、无效或被撤销等需要适用缔约过失责任的情形。也无证据表明存在无权代理行为。

#### 3. 无因管理请求权（《民法典》第979条）

*   **是否可能适用？** **否。** 无因管理是指没有法定或约定义务，为避免他人利益受损失而管理他人事务。本案中，原告出借资金是基于借款合同，属于约定义务，不构成无因管理。

#### 4. 物权请求权（《民法典》物权编）

*   **是否可能适用？** **否。** 物权请求权（如返还原物请求权）针对的是特定物。借款合同纠纷中，原告交付的是货币，货币是种类物，所有权自交付时转移给借款人。原告对已交付的货币不再享有所有权，因此不能主张物权请求权。

#### 5. 不当得利返还请求权（《民法典》第985条）

*   **是否可能适用？** **否（作为主攻方向）。** 不当得利请求权是辅助性的。当合同关系有效存在时，被告占有资金有法律上的原因（借款合同），不构成不当得利。只有在合同无效、被撤销或解除后，被告继续占有资金才可能构成不当得利。本案中，借款合同有效，应优先适用合同请求权。

#### 6. 侵权损害赔偿请求权（《民法典》侵权责任编）

*   **是否可能适用？** **否（作为主攻方向）。** 侵权责任通常适用于人身、财产权益受到侵害的情形。单纯的借款不还，属于合同违约行为，而非侵权行为。除非被告的行为同时构成欺诈、恶意串通等，否则不应适用侵权责任。适用侵权责任举证责任更重，且赔偿范围可能受限。

**结论：** 本案最优先、最合适的请求权基础是**合同请求权**，具体为**借款返还请求权**和**逾期利息支付请求权**。

### 五、诉讼策略建议

#### 1. 主攻请求权基础及理由

*   **主攻：** **合同请求权**，即依据《民法典》第六百七十五条和第六百七十六条，请求被告返还借款本金并支付逾期利息。
*   **理由：**
    *   **最直接、最优先：** 符合本案“借款合同纠纷”的本质。
    *   **举证责任相对清晰：** 原告只需证明“借款合意+实际交付+逾期未还”即可。
    *   **法律保护力度强：** 可以同时主张本金和法定范围内的利息。

#### 2. 备位请求权基础

*   **备位：** **不当得利返还请求权**（《民法典》第九百八十五条）。
*   **适用场景：** 如果法庭经审理认为借款合同因违反法律强制性规定（如高利转贷、职业放贷等）而无效，则合同请求权的基础将不复存在。此时，可主张被告占有资金无法律依据，构成不当得利，应返还本金及法定孳息。

#### 3. 对方最可能提出的3项抗辩及具体应对

| 序号 | 对方抗辩 | 我方应对策略 |
| :--- | :--- | :--- |
| **1** | **“未收到借款”或“收到金额少于借条金额”** | **核心证据准备：** 提供银行转账记录、微信/支付宝转账截图、现金收条等，形成完整的资金交付证据链。若存在“砍头息”，需依据《民间借贷司法解释》第二十七条，主张以实际收到的金额为本金。 |
| **2** | **“已通过现金/转账方式还款”** | **要求对方举证：** 要求被告提供还款的银行流水、收条、证人证言等。我方可以质证其证据的真实性、合法性、关联性。若对方无法提供有效证据，其抗辩不成立。 |
| **3** | **“诉讼时效已过”** | **证明时效中断：** 提供我方在三年内曾向被告催收的证据，如微信聊天记录、短信、邮件、通话录音、律师函、快递单等。证明诉讼时效因主张权利而中断。若无法提供，则需论证本案不适用诉讼时效（如被告一直承认债务）。 |

#### 4. 举证责任分配对我方的影响及应对

*   **影响：** 根据“谁主张，谁举证”原则，我方作为原告，对“借款合同成立并生效”和“被告逾期未还”这两个核心事实承担举证责任。这是诉讼的起点和基础。
*   **应对：**
    *   **强化证据链：** 务必收集并整理好所有能证明借款事实的证据，形成“借条（或合同）+转账记录+催收记录”的完整闭环。
    *   **预判对方证据：** 提前思考对方可能提交的反驳证据（如还款记录），并准备好质证意见。
    *   **利用举证责任倒置：** 对于“已还款”等对被告有利的事实，举证责任在被告。我方应积极要求被告提供证据，并对其证据进行严格质证。
    *   **申请法院调查取证：** 若关键证据（如银行流水）掌握在对方或第三方手中，我方无法自行获取，应及时向法院申请调查令或申请法院依职权调取。

**总结：** 作为原告方律师，我们的核心任务是**构建一个无懈可击的“借款事实”证据链**，并**预判并瓦解被告可能提出的所有抗辩**。合同请求权是我们的主攻方向，同时也要做好合同无效后转向不当得利请求权的备选方案。请尽快提供具体案件事实，以便我为您制定更具针对性的诉讼方案。

#### **二、答辩意见**

答辩人李四就被答辩人张三诉我民间借贷纠纷一案（案号：[待法院立案后填写]），现提出答辩意见如下：

**答辩人认为，被答辩人张三的诉讼请求缺乏事实与法律依据，依法应予全部驳回。** 具体理由如下：

1.  **针对被答辩人第一项诉讼请求（返还借款本金10万元）：** **答辩人予以否认。** 被答辩人仅凭银行转账记录，无法证明该10万元系“借款”。双方之间不存在借款合意，借款合同关系不能成立。被答辩人要求返还本金的主张，无事实基础。
2.  **针对被答辩人第二项诉讼请求（支付逾期利息）：** **答辩人予以否认。** 基于上述理由，借款关系不成立，逾期利息无从谈起。退一步讲，即便法院认定借款关系成立，双方亦从未约定利息，根据法律规定应视为无息借款，且被答辩人主张的月利率1.5%已超过法定保护上限。
3.  **针对被答辩人第三项诉讼请求（诉讼费由被告承担）：** **答辩人予以否认。** 本案系因被答辩人错误主张法律关系所致，诉讼费用应由其自行承担。

**综上，答辩人恳请贵院查明事实，依法驳回被答辩人的全部诉讼请求。**

#### **三、事实与理由**

答辩人针对被答辩人《民事起诉状》中陈述的“事实与理由”，逐项反驳如下：

**（一）关于“2023年3月1日，被告李四因资金周转需要，向原告张三提出借款”的主张**

**答辩人予以否认。** 该主张与事实不符。答辩人从未因资金周转需要向被答辩人提出借款。该笔10万元转账的真实背景是双方共同参与的一个投资项目（详见被告证据1：双方关于项目合作的微信聊天记录）。被答辩人将投资款单方面定性为“借款”，系对事实的歪曲。

**（二）关于“双方口头约定，借款月利率为1.5%”的主张**

**答辩人予以否认。** 双方从未就利息进行过任何口头或书面约定。被答辩人主张存在月利率1.5%的口头约定，但未能提供任何证据予以证明。根据《中华人民共和国民法典》第六百八十条第一款之规定：“禁止高利放贷，借款的利率不得违反国家有关规定。”以及该条第三款之规定：“借款合同对支付利息约定不明确，当事人不能达成补充协议的，按照当地或者当事人的交易方式、交易习惯、市场利率等因素确定利息；自然人之间借款的，视为没有利息。” 本案中，双方均为自然人，且对利息约定存在争议，依法应视为没有利息。

**（三）关于“原告张三曾多次通过微信等方式向被告李四催讨借款。被告李四虽在微信中回复‘再等等’”的主张**

**答辩人予以部分承认，但需补充说明。** 答辩人承认曾收到被答辩人的微信消息，并回复“再等等”。但该回复的上下文背景是双方就投资项目回报问题进行沟通，被答辩人要求提前分配项目收益，答辩人因项目尚未结算，故回复“再等等”。该回复并非对被答辩人“借款”主张的承认，更不构成对借款事实的默示。被答辩人断章取义，将“再等等”曲解为对借款的承认，缺乏事实依据。答辩人要求被答辩人提供完整的、未经剪辑的微信聊天记录，以还原事实真相（详见被告证据1）。

**（四）关于“被告李四至今未向原告偿还任何本金或利息”的主张**

**答辩人予以承认。** 但需要强调的是，答辩人未偿还的根本原因在于，双方之间根本不存在借款合同关系。答辩人收到的10万元系项目投资款，根据项目合作协议，该款项应在项目结束后进行结算分配，而非“偿还”。被答辩人混淆了“借款”与“投资”两种截然不同的法律关系。

**（五）关于“原告与被告之间的借款合同关系合法有效”的主张**

**答辩人予以否认。** 根据《中华人民共和国民法典》第六百七十九条之规定：“自然人之间的借款合同，自贷款人提供借款时成立。” 该条款确立了自然人之间借款合同的“实践性”特征，即合同的成立不仅需要双方达成“借款合意”，还需要贷款人实际“交付借款”。本案中，被答辩人仅能证明“交付借款”（银行转账），但无法证明双方存在“借款合意”。因此，借款合同关系并未依法成立。

#### **一、案由及审理经过**

3. 被告李四回复“再等等”系针对项目收益分配，而非对借款的承认，不构成逾期。

#### **四、法院认定事实**

本院围绕双方争议焦点，对证据进行审查，并运用逻辑推理和日常生活经验，认定事实如下：

**（一）关于款项交付事实**

原告张三提交的**证据1：银行转账记录**，清晰显示其于2023年3月1日向被告李四账户转账100,000.00元。被告李四对该证据的真实性、合法性、关联性均无异议。本院对该证据予以采信，认定原告张三向被告李四交付了100,000.00元款项的事实。

**（二）关于双方是否存在借贷合意（核心争议焦点）**

本院对双方提交的微信聊天记录进行审查，并作出如下认定：

1.  **原告证据2（催款聊天记录）的分析**：该记录显示，原告张三多次向被告李四发送“兄弟，那10万块钱什么时候能还我？”、“最近手头紧，那笔钱能先还一部分吗？”等内容。被告李四的回复均为“再等等”、“过段时间”等。本院认为，在通常的民间借贷语境下，出借人催讨“还钱”，借款人未对“借款”性质提出异议，而是以“再等等”回应，这符合借款关系中借款人承认债务存在但请求宽限的典型行为模式。被告李四主张该回复系针对“项目收益分配”，但未能提供任何证据证明双方曾就项目收益进行过结算或分配，其解释与日常经验法则不符，本院不予采信。

2.  **被告证据2（项目合作聊天记录）的分析**：该记录显示，2023年2月28日，原告张三曾向被告李四发送“这个项目我们一起投，赚了分钱”，被告李四回复“好，我出10万，你出10万，利润对半分”。本院认为，该聊天记录确实表明双方曾就共同投资项目进行过商议，但该商议发生在转账前一日。次日，原告张三向被告李四转账10万元。对于该笔款项的性质，本院认为存在两种可能：一是双方最终达成了投资合意，该10万元为投资款；二是双方在商议投资后，又另行达成了借款合意，该10万元为借款。

3.  **证据矛盾排除与心证形成**：本院注意到，被告李四未能提供任何证据证明双方就投资项目签订了书面协议、约定了风险分担、进行了项目运营或产生了任何收益。在原告张三长达一年多的催款过程中，被告李四从未以“项目亏损”或“尚未结算”为由进行抗辩，其“再等等”的回复在时间上与原告的催款行为高度关联。综合考量以下因素：
    *   **情理判断**：朋友之间因资金周转困难而借款，是常见的社会现象。而共同投资通常需要更明确的书面约定、风险告知和收益分配方案。本案中，双方仅有口头商议，缺乏投资合同的核心要素。
    *   **行为逻辑**：若为投资款，在项目无任何进展或收益的情况下，出借人（投资人）通常不会以“还钱”的方式催讨，而会询问项目进展或要求清算。原告张三持续以“还钱”催讨，被告李四从未以“投资”为由反驳，这一行为模式更符合借贷关系。
    *   **举证责任**：原告张三已初步证明款项交付事实，并提供了催款聊天记录，完成了对“借款合意”的初步举证。被告李四主张投资关系，应就“双方存在投资合意”承担举证责任。但被告李四仅提供了一份商议投资的聊天记录，该记录无法排除双方最终未达成投资合意而转为借款的可能性，其举证未能达到高度盖然性的证明标准。

**综上，本院认为，原告张三提交的证据链（转账记录+催款记录）的证明力，明显优于被告李四提交的证据（商议投资的聊天记录）。依据《最高人民法院关于适用〈中华人民共和国民事诉讼法〉的解释》第一百零八条第一款的规定，本院认定原告张三与被告李四之间存在民间借贷法律关系，借款本金为100,000.00元。**

原告张三主张双方口头约定月利率1.5%，但未能提供任何证据（如聊天记录、录音、借条等）予以证明。被告李四对此予以否认。根据《中华人民共和国民法典》第六百八十条第一款“禁止高利放贷，借款的利率不得违反国家有关规定”及第三款“自然人之间借款的，视为没有利息”的规定，本院认定双方未约定利息，本案借款视为无息借款。

**（一）关于争议焦点一：双方是否存在民间借贷法律关系**

1.  **事理**：如前所述，本院已认定原告张三向被告李四交付了10万元款项，且双方的行为模式符合民间借贷的特征。被告李四主张投资关系，但未能提供充分证据证明投资合意的最终达成。
2.  **法理**：根据《中华人民共和国民法典》第六百七十九条：“自然人之间的借款合同，自贷款人提供借款时成立。”本案中，原告张三已提供借款，双方虽未签订书面合同，但通过原告的交付行为和被告的接受行为，以及后续的催款与回应行为，可以认定双方形成了事实上的借款合同关系。被告李四的抗辩意见，本院不予采纳。
3.  **学理**：王泽鉴先生指出，意思表示的解释应探求当事人的真实意思，而非拘泥于所使用的词句。本案中，双方虽曾商议“投资”，但后续的催款与回应行为，更清晰地揭示了双方将款项定性为“借款”的真实意思。
4.  **情理**：朋友间借贷，往往基于信任，手续简便。若将朋友间因资金周转而发生的款项往来轻易认定为投资，将极大增加社会交易的不确定性，不利于保护善意出借人的利益。

**（二）关于争议焦点二：被告应如何承担还款责任**

1.  **关于本金**：根据《最高人民法院关于审理民间借贷案件适用法律若干问题的规定（2020第二次修正）》第二十七条：“借据、收据、欠条等债权凭证载明的借款金额，一般认定为本金。预先在本金中扣除利息的，人民法院应当将实际出借的金额认定为本金。”本案中，原告张三实际转账100,000.00元，被告李四未能证明存在“砍头息”，故本院认定借款本金为100,000.00元。**对原告张三要求返还本金100,000.00元的诉讼请求，本院予以支持。**

2.  **关于逾期利息**：根据《中华人民共和国民法典》第六百七十六条：“借款人未按照约定的期限返还借款的，应当按照约定或者国家有关规定支付逾期利息。”以及《最高人民法院关于审理民间借贷案件适用法律若干问题的规定（2020第二次修正）》第二十九条第二款第（一）项：“既未约定借期内利率，也未约定逾期利率，出借人主张借款人自逾期还款之日起承担逾期还款违约责任的，人民法院应予支持。”本案中，双方未约定借期内利率和逾期利率，原告张三主张按月利率1.5%计算逾期利息，缺乏依据。本院认为，逾期利息应自原告张三首次有效催告后给予的合理期限届满之日起计算。鉴于原告张三未明确催告的还款期限，本院酌情确定自本案起诉之日（2024年5月20日）起，以全国银行间同业拆借中心公布的一年期贷款市场报价利率（LPR）为标准计算逾期利息。**对原告张三要求按月利率1.5%计算逾期利息的诉讼请求，本院不予支持；对其要求支付逾期利息的诉讼请求，本院部分支持。**
