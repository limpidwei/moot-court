# Agent V2 Skill 系统审计报告与高质量改造方案

> 审计日期：2026-06-08
> 审计范围：`backend/agents/v2/skill.py` 全部 6 个 Skill + `base.py` Skill 注册与调用机制
> 调研方法：代码审计 + Web Search 律师实务文章（交叉询问/举证质证/法律研究/文书起草/争议焦点归纳/判决书撰写）

## 一、执行摘要

**核心结论**：当前 Skill 系统的 `prompt_template` 和 `execute()` 方法**确实是"简单的描述词"**，未能将真实法律实务中的结构化方法论（如请求权基础三层四步法、交叉询问 3C 弹劾法则、质证"定位-定性-说理-结论"四步法）有效编码到 LLM prompt 中。这导致 Agent 的输出停留在"看起来像法律文本"的层面，而非"像资深律师一样思考"。

**严重程度**：中高。当前 Skill 在简单案件中表现尚可，但在复杂案件中缺乏分层推理能力，交叉询问问题质量不稳定，质证意见流于形式，争议焦点归纳过于笼统。

### 2.2 关键问题诊断

#### 问题 1：`prompt_template` 仅为"原则宣言"，缺乏操作步骤

以 `CrossExamSkill` 为例：

```python
prompt_template = """
## 交叉询问能力
你在交叉询问中必须遵循以下规则：
1. 以封闭式问题为主（是/否回答），每个问题只包含一个事实
2. 循序渐进：先固定外围事实，再逼入核心矛盾
3. "关门"技术：先锁定证人当前陈述，再用矛盾证据弹劾
4. 控制证人，不给其"讲故事"的机会
5. 永远不问你不知道答案的问题
6. 获取弹药用于结案陈词，而非当场与证人争论结论
"""
```

**审计发现**：这 6 条原则确实来源于真实交叉询问规则，但 LLM 拿到这 6 条后，并不知道**具体怎么操作**。例如：
- "先固定外围事实"——什么是"外围事实"？怎么识别？怎么固定？
- "关门技术"——具体的问题链怎么设计？第一步问什么？第二步问什么？
- "封闭式问题"——如果证人回答"记不清了"怎么办？如何追问？

真实律师在法学院接受的训练是**具体的话术模板和逻辑链**，而非这些原则。原则只能告诉 LLM "应该做什么"，不能告诉它"怎么做"。

#### 问题 2：`execute()` 的 task prompt 过于通用，缺乏分层推理

以 `LegalResearchSkill.execute()` 为例：

```python
task = f"""请进行法律研究。
【案由】{case_title}
【研究主题】{query}
【角色】{"原告方" if role == "plaintiff" else "被告方"}
请输出：
1. 相关法条及条文内容
2. 司法解释要点
3. 类案裁判要旨
4. 对本案的适用分析"""
```

**审计发现**：
- 没有要求 LLM 按**请求权排序**（合同→缔约过失→物权→无因管理→不当得利→侵权）进行检索
- 没有要求区分**积极要件**（原告举证）和**防御规范**（被告抗辩）
- 没有要求按**"三层四步法"**（请求权成立→未消灭→可行使）进行检视
- 类案检索没有要求**要素抽取比对**

这导致 LLM 输出的法律研究往往是"罗列法条"，而非"围绕请求权基础进行攻防分析"。

#### 问题 3：`CrossExamSkill` 未体现真实交叉询问的 3C 弹劾法则和具体问题链

当前 `execute()` 的 question 分支：
```python
task = f"""请设计交叉询问问题。
【询问对象/目标】{target}
【已知弱点】{weakness_map}
要求：
- 只输出问题本身，严禁输出预估、推理、分析或策略说明
- 封闭式问题为主（是/否回答）
- 每个问题只含一个事实
- 形成问题链，逐步逼近核心矛盾
- 不要在问题前后添加"预估对方回答"等内部思考内容"""
```

**审计发现**：
- 没有要求按**3C 法则**（Commit→Credit→Confront）设计问题链
- 没有要求先**锁定证人陈述**（"您刚才说……"），再展示矛盾
- 没有提供**Few-shot 示例**展示什么是好的交叉询问问题链
- 没有要求考虑**证人可能的回避策略**并设计追问

#### 问题 4：`EvidenceAnalysisSkill` 未体现质证的"定位-定性-说理-结论"四步法

当前输出要求：
```
1. 真实性评价及理由
2. 合法性评价及理由
3. 关联性评价及理由
4. 证明力大小评估
5. 对证据链完整性的影响
```

**审计发现**：
- 缺少**定位阶段**：先明确对方举此证据的"证明目的"是什么
- 缺少**针对性反驳**：没有要求 LLM 先总结对方证明目的，再逐项攻击
- 缺少**特殊证据类型策略**：如电子数据的原始载体要求、鉴定意见的资质审查
- 没有要求输出**"请求法庭不予采信"**的明确结论

#### 问题 5：`DraftingSkill` 未体现最高法要素式文书要求和"说多错多"原则

当前 `prompt_template`：
```
1. 严格遵循最高人民法院发布的文书格式
2. 诉讼请求明确、可执行
3. 事实与理由部分逻辑严密，时间线清晰
4. 证据目录按证明主题分组，标注三性
5. 引用法条准确到条、款、项
```

**审计发现**：
- 没有体现 2025 年最高法推行的**要素式/表格式示范文本**要求
- 起诉状没有强调**"说多错多"**原则（避免在起诉状中暴露全部火力点）
- 答辩状没有强调**"针锋相对、焦点突出"**和**"标注对应证据"**
- 没有区分不同 doc_type 的差异化策略（起诉状要"藏"，答辩状要"攻"）

#### 问题 6：`ModerationSkill` 的争议焦点归纳未体现"诉辩交锋法"和"请求权基础分析法"

当前 `summarize_issues` task：
```
要求：
1. 区分事实争议和法律争议
2. 每项标注原告主张和被告主张
3. 依据《民诉法解释》第226条，焦点应来源于双方主张和证据
```

**审计发现**：
- 没有要求按**"诉辩交锋法"**比对原告诉请与被告抗辩，找出矛盾差异
- 没有要求按**"请求权基础分析法"**将争议拆分为要件化问题（如"合同是否成立→是否生效→是否存在违约"）
- 没有要求**征求当事人意见**的动态确认机制
- 没有要求**分阶段、分层次**推进（先概括性焦点，再具体化）

#### 问题 7：`AdjudicationSkill` 未体现"五理"说理体系和自由心证公开

当前 `prompt_template`：
```
1. 严格按格式：案由及审理经过、原告诉求、被告答辩、法院认定事实、法律适用及论证、判决主文
2. 事实认定以证据为依据，说理透明
3. 胜率评估四维度
4. 自由心证过程公开化
```

**审计发现**：
- "自由心证过程公开化"只是一句口号，没有具体要求法官在判决书中写明**"为什么采信这份证据、为什么不采信那份证据"**
- 没有要求**"五理"说理体系**（事理、法理、学理、情理、文理）
- 没有要求**"胜败皆明"**的回应式说理（对当事人的每个主张都要回应）
- 没有要求以**争议焦点为主线**组织判决理由

### 2.4 Skill 调用权限审计

**当前权限设计（合理）**：
- `PlaintiffAgentV2`：LegalResearch, Drafting, EvidenceAnalysis, CrossExam

## 三、真实法律实务工作流调研

### 3.1 法律研究：请求权基础"三层四步法"（吴香香）

来源：[吴香香：关于请求权基础在实务中的适用，我总结了三层四步法！](https://www.sohu.com/a/896000276_121124318)

**三层检视结构**：
1. 请求权是否**成立**
2. 成立后是否**消灭**（清偿、提存、抵销、免除、混同）
3. 是否存在行使**障碍**（抗辩权）

**四步检视内容**：
| 步骤 | 检视内容 | 举证责任 |
|------|----------|----------|
| 第一步 | 请求权成立要件（积极要件） | 原告举证 |
| 第二步 | 权利未发生的抗辩（防御规范） | 被告反证 |
| 第三步 | 权利已消灭的抗辩 | 被告反证 |
| 第四步 | 权利阻止的抗辩（诉讼时效等） | 被告反证 |

**请求权排序**：合同→缔约过失→物权→无因管理→不当得利→侵权

**类案检索方法**：要素抽取法（抽取关键要素→比对相似性→选择强化或打破匹配）

### 3.2 交叉询问：封闭式提问四模型 + 3C 弹劾法则

来源：[证人出庭作证时，律师如何用"封闭式提问"控制局面](https://www.163.com/dy/article/K1N419T2055672GW.html)、[案例解读！刑辩律师必知"交叉询问"的套路](http://www.guokekunlvshi.com/a/xsfl/lsxfyfw/3496.html)

**封闭式提问四模型**：
1. **事实切割术**：将叙事拆解为可验证的独立单元（锁定时空要素、动作细节）
2. **矛盾激发链**：用闭环问题暴露逻辑漏洞（单点爆破、循环验证）
3. **记忆压强测试**：高密度细节追问击穿伪证（时空锚定、感官限定）
4. **归谬法**：按证人自身逻辑引申推导，得出荒谬结论

**3C 弹劾法则**：
1. **Commit（确认立场）**：让证人确认当庭陈述
2. **Credit（强化情境）**：强调先前陈述的正式性
3. **Confront（对质）**：用记录在案的证词当庭对质

**六条戒律**：一问一答、问题连续性、优先使用引导性问题、归谬法、绝对控制与倾听并重、庭前准备清单

### 3.3 举证质证："三性"审查 + "定位-定性-说理-结论"四步法

来源：[如何对对方提供的证据进行质证？（从三性出发）](http://dt.cehuiyc.com/newspage/news.asp?id=23392)、[赵启太律师深度解析民事诉讼举证质证实务精髓](https://m.sunlawyers.com/dynamics25793.html)

**三性审查具体角度**：
| 特性 | 审查要点 |
|------|----------|
| 真实性 | 是否原件/原物；有无涂改、增减、剪辑；是否违背常理 |
| 合法性 | 取证主体/程序是否合法；证据形式是否符合法定要求；是否非法证据 |
| 关联性 | 是否指向本案争议焦点；是否仅为间接证据；是否已被自认 |

**质证意见四步法**：
1. **定位**：明确证据名称、编号、证明目的
2. **定性**：围绕三性逐项发表意见
3. **说理**：结合具体法律条文与案件事实矛盾点
4. **结论**：请求法庭依法不予采信/部分采信

**特殊证据类型策略**：
- 电子数据：要求展示原始载体、核查哈希值/时间戳
- 鉴定意见：审查机构/人员资质、检材移交记录
- 证人证言：证人是否旁听、与当事人利害关系

### 3.4 文书起草：最高法要素式文本 + "藏与攻"的差异化策略

来源：[最高法发布新版民事起诉状、答辩状示范文本](http://www.ecqfy.hbfy.gov.cn/DocManage/ViewDoc?docId=83addde2-7ea5-47c5-a4b1-5a8bb520f9f4)、[律师撰写起诉状、答辩状、代理词的实务要点](https://mp.weixin.qq.com/s/5MOkJ4A0E7wwOxvYp4ll6w)

**起诉状"藏"的策略**：
- "说多错多"：避免对己方不利的事实描述
- "切勿过度论证"：起诉状不是代理词，不要和盘托出
- "隐藏火力点"：庭审才是详细论证的环节
- 2025 年起需适应**要素式/表格式示范文本**

**答辩状"攻"的策略**：
- 针锋相对：逐项回应起诉状"事实与理由"
- 标注证据："详见被告证据 1"形成逻辑闭环
- 多理性分析，少情绪化表达

### 3.5 争议焦点归纳：诉辩交锋法 + 请求权基础分析法 + 动态提炼法

来源：[庭审争议焦点，法官建议这样归纳](https://www.thepaper.cn/newsDetail_forward_19698062)

**核心方法**：
1. **诉辩交锋法**：比对原告诉请与被告抗辩，找出矛盾差异
2. **请求权基础分析法**：将争议拆分为要件化问题（合同是否成立→是否生效→是否违约）
3. **动态提炼法**：先概括性焦点，再随证据展开细化为具体焦点
4. **征求当事人意见**：依据《民诉法解释》第 226 条，就归纳的焦点征求当事人意见

### 3.6 判决书撰写："五理"说理体系 + 自由心证公开

来源：[论民事裁判文书说理机制改革与法官自由心证公开的有机结合](https://hszy.hebeicourt.gov.cn/article/detail/2016/11/id/5918170.shtml)、[完善民事裁判文书写作思路与说理的思考](http://www.sdcourt.gov.cn/jnanszqfy/389687/389690/7211338/index.html)

**五理体系**：
| 类型 | 内容 |
|------|------|
| 事理 | 对案件主要事实的认定提供依据并说明理由 |
| 法理 | 援引法律、司法解释准确完整 |
| 学理 | 必要时运用法学理论辅助说理 |
| 情理 | 结合道德规范、生活经验、公序良俗 |
| 文理 | 逻辑严密、用语规范、文字精练 |

**自由心证公开要求**：
- 证据分析阶段：写明采信结果 + 内心判断过程
- 事实认定阶段：写明内心确信的事实经过
- 判决理由阶段：阐明自由裁量的具体考量

**回应式说理**：对当事人的诉讼请求、答辩意见进行针对性回应，做到"胜败皆明"

## 四、高质量 Skill 改造方案

### 4.1 改造原则

1. **从"原则描述"到"操作手册"**：每个 Skill 的 `prompt_template` 必须包含**具体操作步骤**，而非仅列原则
2. **嵌入真实方法论**：将请求权基础三层四步法、3C 弹劾法则、质证四步法、五理体系等真实方法论编码到 prompt 中
3. **增加 Few-shot 示例**：在 `execute()` 中提供 1-2 个高质量的输入/输出示例
4. **分层推理**：要求 LLM 先进行内部推理（如"我先分析请求权基础……"），再输出最终内容
5. **差异化策略**：根据不同 doc_type/task_type 提供差异化的指令（如起诉状"藏"vs 答辩状"攻"）

### 4.2 各 Skill 具体改造方案

#### 改造 1：`LegalResearchSkill` → 请求权基础驱动型法律研究

**`prompt_template` 改造**：
```python
prompt_template = """
## 法律研究能力

你进行法律研究时必须遵循"请求权基础分析法"：

### 第一步：请求权检索与排序
按以下顺序检索可能的请求权基础：
1. 合同请求权（《民法典》合同编）
2. 缔约过失请求权（《民法典》第500条）
3. 物权请求权（《民法典》物权编）
4. 无因管理请求权（《民法典》第979条）
5. 不当得利返还请求权（《民法典》第985条）
6. 侵权请求权（《民法典》侵权责任编）

### 第二步：三层四步检视
对每个可能的请求权基础，按以下框架检视：
- 第一层：请求权是否成立？（积极要件由原告举证）
- 第二层：成立后是否消灭？（清偿、提存、抵销、免除、混同）
- 第三层：是否存在行使障碍？（诉讼时效、同时履行抗辩权等）

### 第三步：辅助规范与防御规范检索
围绕主要规范，检索周边解释性规范、但书条款及例外规定。

### 第四步：类案检索（要素抽取法）
1. 从待决案件中抽取关键要素
2. 检索 3-5 个相似判例
3. 比对待决案件与类案的要素相似性
4. 根据代理立场（原告/被告）选择强化或打破要素匹配

### 输出要求
- 按请求权排序逐一分析
- 明确每项积极要件的举证责任分配
- 类案必须标注案号、法院层级、裁判要旨
- 最后给出明确的诉讼策略建议（主攻哪条请求权基础，备位选择是什么）
"""
```

**`execute()` 改造**：
```python
async def execute(self, agent, context: dict) -> str:
    query = context.get("query", "")
    case_title = context.get("case_title", "")
```

## 六、结论

当前 Skill 系统的根本问题是**"知道原则，但不知道怎么操作"**。真实的法律实务不是记住几条原则就能做好的，而是需要经过数年训练才能掌握的结构化方法论（如请求权基础三层四步法、3C 弹劾法则、质证四步法）。

改造的核心思路是：
1. 将真实律师/法官的工作流程**操作化、步骤化**
2. 在 prompt 中嵌入具体的**方法论框架**和**检查清单**
3. 通过**差异化策略**（起诉状"藏"vs 答辩状"攻"）提升输出针对性
4. 要求 LLM 进行**分层推理**（先分析再输出），而非直接生成

这些改造不需要修改架构，只需要重写 `prompt_template` 和 `execute()` 中的 task prompt，风险低、收益高。
